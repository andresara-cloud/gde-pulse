Enter your Advocu API key

Your Advocu API key can be found here: https://app.advocu.com/settings/integrations/personal-api

Paste your personal Advocu API key to auto-sync your GDE profile and recent activities.

Note: The Advocu API key is optional. If you do not enter an Advocu key, you can continue configuring your profile below, but you will experience reduced functionality (such as automated posting of activity drafts to Advocu and automatic background activity syncing).

Write-only & AES-256-GCM encrypted: Your Advocu key is encrypted server-side (backed by Google Cloud Secret Manager) and locked to your Google account (request.auth.uid, client reads & collection listing disabled). It is never stored in plain text, not readable in the database console (even by project admins), never cached in localStorage or exposed to the Agent/SQL APIs, and can be permanently purged anytime via Delete Profile.
